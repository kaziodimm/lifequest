# Habidoo MVP Scope

## Goal

Build a mobile-first web MVP that proves whether a Life Technology Tree makes real-life progress feel more meaningful than a todo list.

The MVP should be simple enough to ship quickly, but visually strong enough to show in short-form videos.

## Core MVP Rule

The Life Tree is the product.

Everything else exists to support the Life Tree.

## In Scope

### Home

- Avatar/profile summary.
- Level.
- Total XP.
- XP progress bar.
- Current streak.
- Today's completion percentage.
- Quick action to open Life Tree.

### Life Tree

- Visual technology tree.
- Scrollable mobile-friendly canvas.
- Connected nodes.
- Locked technologies.
- Available technologies.
- Unlocked glowing technologies.
- Reusable TreeNode architecture.

### Daily Command Center

- Top 3 missions.
- Tiny first step.
- Each mission connected to a technology.
- 24-hour planner foundation.
- Morning decision-fatigue reduction.

### Statistics

- 7-day progress.
- XP growth foundation.
- Category growth foundation.
- Future-ready structure for deeper analytics.

### Profile

- Level.
- Achievements.
- Unlocked technologies.
- Life score.

### XP and Levels

- Completing missions gives XP.
- Unlocking technologies gives XP.
- Progressive level thresholds.

### Streaks

- Daily completion builds streaks.
- Milestones prepared: 3, 7, 14, 30, 100 days.

### Themes

Keep the visual style architecture ready for:

1. Focus Dark
2. Soft Light
3. Pixel Quest
4. Cyber Calm
5. Nature Progress

MVP begins with Focus Dark.

## Out of Scope for Version 1

- Backend.
- Supabase auth.
- Resend emails.
- Stripe.
- Ads.
- Mobile app store builds.
- Global leaderboards.
- Friends ranking.
- Guilds.
- Complex avatar customization.

These should be prepared architecturally, not implemented yet.

## Technical Requirements

- Next.js App Router.
- React.
- TypeScript.
- Tailwind CSS.
- shadcn/ui-style components.
- Recharts.
- Zustand.
- localStorage persistence.
- Vercel-ready structure.

## MVP Quality Bar

The MVP should feel:

- strategic
- premium
- mobile-first
- visually memorable
- gaming inspired
- useful immediately

It should not feel like:

- a generic todo list
- a habit tracker template
- a corporate dashboard
- a childish RPG clone

## First Test Flow

A user should be able to:

1. Open Habidoo.
2. Understand that the Life Tree is the main mechanic.
3. See current level, XP, streak, and today's missions.
4. Open the Life Tree.
5. Understand locked, available, and unlocked technologies.
6. Complete a daily mission.
7. Gain XP.
8. Unlock a technology.
9. Feel that real-life progress is visually meaningful.
