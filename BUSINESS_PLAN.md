# Habidoo Business Plan

## 1. Product Idea

Habidoo is a playful daily habit and task app for people who want to make everyday progress without feeling like they are using a strict productivity system.

The app turns daily actions into a light game loop:

1. Start with a tiny step.
2. Complete habits and tasks.
3. Earn XP.
4. Keep streaks alive.
5. Level up a profile or character.
6. Unlock rewards, themes, and visual progress.

Habidoo should feel more like a friendly daily companion than a serious task manager.

## 2. Target Audience

Initial audience:

- People who struggle to start tasks in the morning.
- Students.
- Freelancers and remote workers.
- People building routines after moving, studying, changing jobs, or recovering structure.
- Users who enjoy Duolingo, Finch, Forest, Habitica, Streaks, and casual mobile games.

Markets:

- Czechia first for interface testing.
- English-speaking market next.
- Russian and Ukrainian audiences as strong secondary segments.
- Later: global mobile users through app stores.

## 3. Core Problem

Many people do not need another complex todo app. They need a low-friction way to begin, continue, and feel progress.

Habidoo focuses on this moment:

> I know what I should do, but I cannot start or stay consistent.

## 4. Differentiation

Habidoo is not a Habitica clone.

Key differences:

- Tiny first step as a core mechanic.
- Strong visual identity and mascot.
- Multiple visual themes.
- Mobile-first playful UI.
- Simple setup.
- Reward partial progress instead of punishing users too hard.
- Focus on daily return and emotional momentum.

## 5. MVP

The first public version should include:

- Account system with Supabase.
- Dashboard.
- Daily tasks.
- Habits.
- XP and levels.
- Streaks.
- Basic profile or character.
- Language switch.
- Theme switch.
- Basic statistics.
- Vercel deployment.
- Analytics for unique users and retention.

## 6. Monetization

The core product should remain free.

Future revenue paths:

- Mobile ads.
- Rewarded ads for streak shields, bonus cosmetics, and extra visual items.
- Premium no-ads plan.
- Paid themes and cosmetic packs.
- Optional supporter upgrade.
- Stripe for web premium when the product has proven retention.

Do not block the main habit/task loop behind payment.

## 7. Growth Strategy

Primary channel:

- Instagram Reels.
- TikTok.
- YouTube Shorts.

Content angles:

- Make your day feel like a game.
- XP for real life.
- Tiny first step instead of another failed day.
- Morning routine as a quest.
- Habit streaks with a cute companion.
- Czech-first productivity app with global potential.

## 8. Metrics

Track from day one:

- Unique visitors.
- Signups.
- Activated users.
- Created habits.
- Completed habits.
- Created daily tasks.
- Completed daily tasks.
- Day 1 return.
- Day 7 retention.
- Streak length.
- Theme changes.
- Language selection.

Main MVP metric:

> Does the user come back tomorrow?

## 9. Phases

### Phase 1: Foundation

Create product docs, design direction, app architecture, and MVP scope.

### Phase 2: Web MVP

Build the first usable app with auth, dashboard, habits, tasks, XP, streaks, themes, and localization.

### Phase 3: Visual Identity

Add mascot direction, custom icons, stronger themes, animations, empty states, and game-like feedback.

### Phase 4: Launch

Deploy to Vercel, connect Supabase, add analytics, and test with real users.

### Phase 5: Growth

Run Reels/TikTok experiments, collect feedback, improve onboarding and retention.

### Phase 6: Mobile and Revenue

Prepare PWA/mobile wrapper, test ads, add rewarded ads, and consider premium/cosmetics.
